# jadb - Just Another Discord Bot

A Discord bot for my college club.

It only uses `/` commands as I find them easier to work with both 
coding-wise and usage-wise.

## Commands

### General
- `/hello` : The bot gives a greeting!
- `/help` : The bot displays useful information about the bot.
- `/serverinfo` : The bot displays information about the Discord server the command was used in.
